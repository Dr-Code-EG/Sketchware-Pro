# 2. Pin r8 to the 8.11.x line until DependencyResolver is migrated

Date: 2026-04-25

## Status

Accepted

## Context

Library updates in PR #1 brought the Android Gradle Plugin to 8.13.x and
the standalone `com.android.tools:r8` artifact to its current latest. r8
8.13+ migrated several internal API signatures, notably
`D8Command.Builder.addClasspathFiles`, from `java.io.File` to
`java.nio.file.Path`. The on-device dependency resolver
(`mod/pranav/dependency/resolver/DependencyResolver.kt`) calls the older
signature directly and fails to compile against the newer API.

## Decision

We pin `com.android.tools:r8` to `8.11.18` in `app/build.gradle` and add
a Renovate package rule (`<8.12.0`) so automated bumps don't override the
pin. A follow-up task will port `DependencyResolver.kt` to the new Path-
based API and remove the pin.

## Consequences

* Builds remain green with current AGP and Kotlin versions.
* On-device dependency resolution continues to work unchanged.
* We carry technical debt until `DependencyResolver.kt` is migrated.
